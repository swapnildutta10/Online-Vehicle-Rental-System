# 🚗 Online Vehicle Rental System

A modern web-based platform designed to simplify the process of **finding, booking, and managing vehicle rentals online**. The system provides a convenient experience for customers while offering powerful management features for administrators.

## 📌 Overview

The **Online Vehicle Rental System** allows customers to explore available vehicles, view detailed information, check availability, and make rental bookings through an intuitive interface. Administrators can efficiently manage vehicles, users, bookings, and payment records from a centralized dashboard.

The project focuses on creating a **simple, secure, and efficient digital rental experience**.

## ✨ Key Features

- 🔐 User Registration & Authentication
- 🚘 Browse Available Vehicles
- 🔎 Search & View Vehicle Details
- 📅 Vehicle Booking & Availability
- 👤 User Dashboard
- 🛠️ Admin Dashboard
- 🚗 Vehicle Management
- 👥 User Management
- 📋 Booking Management
- 💳 Payment History
- 📱 Responsive User Interface

## 🧑‍💻 Technology Stack

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Styling | Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| Authentication | Firebase |
| Version Control | Git & GitHub |

## 👥 User Roles

### Customer
Customers can register, browse vehicles, check availability, make bookings, and manage their rental history.

### Administrator
Administrators can manage vehicles, users, bookings, and payment information through the admin dashboard.

## 🎯 Project Objectives

- Simplify the vehicle rental process.
- Reduce manual booking and management.

- Improve customer convenience.
